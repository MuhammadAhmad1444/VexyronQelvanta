# Vexyron Qelvanta Ltd — website

React + Vite + Tailwind site. Company details live in `src/company.js`; products and services in `src/data.js`.

```bash
npm install
npm run dev     # local dev server
npm run build   # writes index.html + assets/ to the repo root
```

The repo root is the deployable site (Apache `.htaccess` included for client-side routing).
